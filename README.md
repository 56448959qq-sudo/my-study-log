# 学習ログ

このレポジトリは、学習ログアプリに育てるための土台として使います。

HTML/CSS/JavaScript と localStorage だけで動く、学習記録アプリの土台です。学習日、集中度、学習メモを保存して、日々の習慣を見える化できます。

個人情報（学校名や氏名など）は入れず、汎用的な学習記録として使える構成にしています。

## 📱 使い方

`index.html` をブラウザで開くだけで使えます。ビルドやサーバー起動は不要です。

```text
study-log/
├── index.html
├── styles.css
├── app.js
├── README.md
├── LICENSE
└── image.png
```

## 機能

- 学習日を自動入力
- 集中度を5段階で選択
- 学習メモを保存
- 日付ごとに1件の記録として保存
- 同じ日付で保存すると上書き
- 過去の学習記録一覧表示
- 学習記録の編集と削除
- メモ検索
- 集中度フィルター
- 最近7件の集中度の変化を表示する学習リズム

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

外部ライブラリは使っていません。

## localStorage

保存キーは `study-log.entries.v1` です。

データは次のような配列で保存されます。

```json
[
  {
    "id": "example-id",
    "date": "2026-04-29",
    "mood": "focused",
    "note": "今日は重要なポイントを復習した",
    "createdAt": "2026-04-29T10:00:00.000Z",
    "updatedAt": "2026-04-29T10:00:00.000Z"
  }
]
```

## 集中度データ

集中度は次の5種類です。

| 値 | 表示 | スコア |
| --- | --- | --- |
| `focused` | 高い | 5 |
| `steady` | 良好 | 4 |
| `normal` | 普通 | 3 |
| `tired` | 低め | 2 |
| `low` | 低い | 1 |

学習リズムでは、最近7件の記録をこのスコアに変換して、SVGの波形グラフとして表示します。

## 教材で説明しやすい流れ

1. フォームから値を受け取る
2. JavaScript の配列に学習データを追加する
3. `JSON.stringify` で localStorage へ保存する
4. `JSON.parse` で localStorage から読み込む
5. 配列をもとに一覧と学習リズムを再描画する
